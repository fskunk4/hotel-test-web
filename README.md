# Hotel Aureline – Next.js Demo Site

A small multi-page hotel marketing website built with Next.js App Router and TypeScript.

## Pages

- Home
- Rooms
- Dining
- Spa & Wellness
- Contact
- Reservations

## Stack

- Next.js App Router
- TypeScript
- React
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Other scripts

```bash
npm run lint
npm run build
npm run start
```

## Notes

- Minimal dependency footprint
- Shared layout, header, footer, and page hero components
- Accessible forms, skip link, responsive layout, and per-page metadata
